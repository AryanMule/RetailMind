RetailMind AI
RetailMind AI is an end-to-end retail AI platform built incrementally.

Each development day adds a new machine learning capability to the same codebase.

Day 1: Customer Churn Prediction
The first module builds a machine learning pipeline that:

loads customer churn data
preprocesses numerical and categorical features
trains a baseline churn classifier
evaluates the model
saves the trained pipeline
provides a simple prediction service
Project Structure
data/ stores datasets
src/ contains Python source code
models/ stores trained machine learning pipelines
notebooks/ contains experimentation notebooks
